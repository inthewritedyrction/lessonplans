# Production Standard — Grade 8 ELA Lesson Materials (Ms. Briggs)

Claude's role here is **production assistant**, not lesson designer. The teacher makes every
instructional decision; Claude builds finished materials from the approved plan.

## Ground rules

- Do NOT change objectives, standards, texts, pacing, reading assignments, differentiation
  decisions, or instructional sequence unless explicitly asked.
- Build only the deliverables requested. Do not redesign a lesson unless asked for revisions.
- Before building, briefly confirm what files/content were received and what the task is.
- Do not build a lesson until its plan is explicitly approved and provided.
- **Excerpts:** never source, invent, or substitute outside text. Use only the exact assigned
  text/page references provided, or leave a clearly labelled placeholder
  (model: Day 1 slide 10 / packet "EXCERPT PROVIDED BY MS. BRIGGS"). Ask before using a different passage.

## Permanent exemplar set

`exemplars/week09/` — Week 9 Day 1 (Mon) and Day 2 (Tue). These are finished models, not drafts;
never edit them. **Day 2's teacher copy is the standard for all teacher-facing materials** until
another teacher-copy exemplar is provided.

## Block structure

- One continuous **80-minute run of show**. Planning principle: ~50 min whole-class /
  teacher-directed flowing into ~30 min of increasingly independent work. Never format these as
  two separate blocks.
- Recurring flow: Do Now (Box 01) → tool/concept box (Box 02) → context / read-aloud →
  teacher model of Row M (short) → ★ LEAF planned scholar think-aloud (purple dashed strip) →
  partner reading on Rows 2–4 (each partner writes) → synthesis / share → independent work →
  protected exit ticket below the "✂ CUT OR FOLD HERE · EXIT TICKET · ON YOUR OWN" line →
  optional cold call + preview of next day.
- Think-aloud protocol: silent 30–45 sec (thumb on chest) → named scholar starts with
  "First I…" → teacher presses, doesn't answer → second scholar builds / revises / challenges
  ("I agree / would revise that because ___. I noticed ___.") → release.
- The exit ticket is never cut. Each run of show names what gets shortened first.
- The page-2 map/tracker is the evidence bank feeding the day's (or next day's) writing.
- **Continuity:** the Day 2 Tone and Mood Map + THEME parking lot set up Day 3 (Theme + Legacy,
  Course Mojo task). Preserve that link when Day 3 is built.

## Differentiation

- **Universal packet** with the same endpoint and learning target for all scholars. Do NOT
  create four packets unless explicitly requested.
- Accessibility built into the universal packet: models, sentence stems, chunked directions,
  page-number cues, word banks, evidence banks, oral rehearsal opportunities.
- **Morehouse** support lives mainly in the teacher copy as live scaffolding / intervention
  notes (e.g., sit with a pair for one row, 1-min oral rehearsal before writing).
- **Alabama A&M** extension via "Done Early" / Stretch thinking where appropriate.
- Do not name **SUNY Albany** or **Oglethorpe** in materials unless group-specific
  differentiation is requested.
- Group reference (only when group-specific work is requested): Morehouse ≈ 3rd-grade-accessible
  steps, frames, guided paragraph construction · SUNY Albany ≈ 5th-grade-accessible ·
  Oglethorpe = grade level · Alabama A&M = highest rigor + extension.

## Deliverables (default for a completed lesson)

| Deliverable | Format | Notes |
|---|---|---|
| Student packet | PDF (US Letter, 3 pp.) | exemplars built from HTML via WeasyPrint |
| Teacher copy | PDF (landscape) | Day 2 structure |

outputs so materials can be revised later.

## Formatting conventions

**Student packet**
- Top: 5-day tab strip (Day 1 Anne + Peter · Day 2 Tone + Mood · Day 3 Theme + Legacy ·
  Day 4 Entering Night · Day 5 Writing Synthesis) with current day highlighted + "DAY X" pill.
- All-caps title, italic source line (text · act/scenes · pages), Name / Date / Class fields,
  teal LEARNING TARGET box.
- Numbered boxes 01–06: colored header bar + subtitle + right tag (time, "EVIDENCE BANK", etc.).
  Colors: yellow Do Now, blue tool, purple model/independent, teal tracker/transitions,
  coral exit ticket.
- Map/tracker: yellow "M" model row, numbered rows with page cues ("LOOK ON p. ___" /
  "CHUNK 1"), purple dashed SHOW YOUR THINKING strip (First I… / Then I noticed… /
  So I decided… / Because…).
- Page-number pills on quotes. Students are "scholars."
- Footer: `WEEK X · DAY X · ENCOUNTERING EVIL · GRADE 8 ELA · MS. BRIGGS` + `PAGE X OF 3`;
  pages 2+ carry a running header with the text title and DAY pill.

**Teacher copy** (model: `Week9_Day2_Teacher_Copy.pdf`)
- P. 1 LESSON AT A GLANCE: title, source + standards, Essential Question, Learning Target,
  key distinction box ("post it, keep it up all period"), ★ LEAF action step, Milestones
  alignment, run-of-show table (minutes · segment · packet location · slide), "What changed
  from Prather (and why)", prep checklist.
- P. 2 TEXT + KEY: Prather segment → this edition page map, passage key, numbered
  misconceptions → clarifying moves, Briggs Checks, "when a scholar struggles" ladder,
  Morehouse note.
- P. 3+: one page per segment — minute badge + colored title bar + packet/slide chips;
  left: packet-page thumbnail with active box outlined in red; right: labelled beats
  (GET THEM HERE · SAY WHILE DOING · SCHOLARS DO · ASK · LISTEN FOR · IF INCOMPLETE /
  IF STALLED · CHECK · PACE CALLS · MOVE ON WHEN · TRANSITION in bold with slide number).
- PRATHER tag on moves drawn from the Prather source.
- Footer: `WEEK X · DAY X · TEACHER COPY · <TITLE> · MS. BRIGGS` + `TEACHER COPY · PAGE X`.

**Slides**
- Slide 1: dark title slide (WEEK · DAY · UNIT kicker, title, source line, EQ + LT cards).
- Content slides: numbered circle icon matching packet box, title + subtitle, packet chip
  ("PACKET P. 2 · ROW M"), pastel cards, dark takeaway bar, slide number.
- Order follows the packet. Speaker notes: SAY / ASK / LISTEN FOR / pace calls / TRANSITION.
