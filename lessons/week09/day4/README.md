# Week 9 · Day 4 (Thu) · Entering Night: Moishe’s Warning and the Symbol of Night

Prather Week 2, Day 4, taught as Week 9. Scholars do the first read of *Night* pp. 3–22 at home with the guided homework; Thursday is the reread, teaching, discussion, and writing.

| File | What it is |
|---|---|
| `Week9_Day4_Guided_Reading_Homework.docx` | 2-page editable homework (Opening Reading Check), given the night before with PDF pages 18–36 |
| `Week9_Day4_Student_Classwork.pdf` | 5-page large-print classwork, open answer boxes |
| `Week9_Day4_Teacher_Copy.pdf` | 18-page large-print landscape teach-through |
| `Week9_Day4_Slides.pptx` | 12 slides with speaker notes |
| `src/` | Editable sources: `student_classwork.html` + `packet.css`, `teacher_copy.html` + `teacher.css`, `build_homework.js`, `build_slides.py`, `build.py` |

## Rebuild

```
cd src
python3 build.py
```

Rebuilds all four files. Needs `weasyprint`, `python-pptx`, `Pillow`, `poppler-utils`, Node with the `docx` package, and the TeX Gyre Adventor font.

## Pages

Page numbers are the printed book pages (this edition). Book pp. 3–22 = PDF pages 18–36 of the print file. In the two-pages-per-sheet PDF, book pp. 3–22 are PDF pages 14–24.
